# User Stories - Luxeyline

1. As a new user, I want to sign up with my email and password so that I can create an account and access the app.
2. As a registered user, I want to log in with my credentials so that I can securely access my account.
3. As a user, I want to view a home screen with featured properties so that I can quickly browse available listings.
4. As a user, I want to explore properties using search and filters so that I can find listings that match my preferences.
5. As a user, I want to view detailed information about a property (photos, price, location, description) so that I can decide whether to buy it.
6. As a user, I want to save/favorite properties I'm interested in so that I can view them again later under "My Properties."
7. As a buyer, I want to initiate a "Buy Property" request so that I can start the process of purchasing a listed property.
8. As a user, I want to send and receive messages with property owners/agents so that I can communicate directly about a listing.
9. As a user, I want to access my profile and settings so that I can manage my account information and preferences.
